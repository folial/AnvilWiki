## Exark Building Tier List (1.0)

Based on the core resource loop from the official Steam description:

| Tier | Building Type | Why |
|------|--------------|-----|
| **S** | Food buildings | Foundation of your economy; stockpiles increase cycle speed |
| **A** | Production buildings | Lets you construct more buildings |
| **B** | Inspiration buildings | Hire crew for powerful bonuses |
| **C** | Gold buildings / Markets | Useful shortcuts, but not essential |

## How to Use This Tier List

- Early game: Focus on S and A tier buildings.
- Mid game: Add B tier buildings for crew bonuses.
- Late game: C tier buildings for optimization.
